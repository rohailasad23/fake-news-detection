1Project kya hai

Ye ek website hai jisme aap news headline ya article daalte hain aur system 2 kaam karta hai:

  1. AI detection: trained model (RoBERTa, CNN, LSTM, Logistic Regression, Random Forest, SVM) batata hai news REAL hai ya FAKE, confidence % ke saath.
  2. Blockchain source traceability: news ka source Ethereum blockchain pe ek unique hash ke saath record hota hai. Record baad mein badla ya mitaya nahi ja sakta, aur system batata hai source verified hai ya nahi.

Technologies (proposal ke mutabiq): Python, Scikit-learn, PyTorch, NLTK, Pandas, Ethereum (Solidity + Ganache), Flask, HTML/CSS/JavaScript. Datasets: FakeNewsNet + LIAR.

4Pehli dafa setup (one-time)

1

Zip extract karein

Zip file pe right-click → Extract All… → koi chhota path chunein, jaise D:\fake-news-detection.

Zip ke andar se files mat chalayein — pehle poora extract karein. OneDrive wale folders se bhi bachein.
2

Python 3.12 install karein

https://www.python.org/downloads/ se Python 3.12 ka Windows installer (64-bit) download karein.

Installer ki pehli screen pe "Add python.exe to PATH" ka checkbox zaroor tick karein, phir Install Now.
3

Node.js install karein

https://nodejs.org se LTS version download karke default settings ke saath install karein (Next → Next → Install).

4

setup.bat pe double-click karein

Ek black window khulegi aur 6 steps chalenge: Python check → Node check → environment banana → packages install → Ganache → models check. Takreeban 10–30 minute lagenge (PyTorch bara package hai, aur Windows Defender files scan karta hai) — window band na karein.

Aakhir mein "Setup complete" aur ek test prediction nazar aaye to setup kamyab hai. Ye kaam sirf ek dafa karna hai.

Agar Windows "Windows protected your PC" dikhaye to More info → Run anyway dabayein.

5Har dafa run karna

▶

start.bat pe double-click karein

Ye khud ba khud:

  1. Ganache (local Ethereum blockchain) chalata hai — ek chhoti window minimize ho kar khulti hai,
  2. Web app (Flask) chalata hai — doosri window,
  3. App tayyar hone par browser mein http://127.0.0.1:5000 khol deta hai.

Band karna: "Ganache - Ethereum node" aur "Fake News Detection - web app" — dono windows band kar dein.

Pehli analysis mein 15–30 second lag sakte hain kyunke RoBERTa model memory mein load hota hai. Uske baad har analysis jaldi hoti hai.

8Demo / viva checklist

  • App khule to upar right pe "6 AI models" aur "Ethereum · block …" dono green hon.
  • Fake example: "Celebrity secretly replaced by a body double years ago, insiders claim", source gossipblog.net → FAKE + Unverified + naya block.
  • Real example: "Senate passes bipartisan infrastructure bill after months of negotiations", Source URL https://www.reuters.com/world → REAL + ✅ Verified.
  • Duplicate: wahi fake headline dobara analyze karein → "already on the ledger", original record dikhega.
  • Source Mismatch: Trace source mein fake headline + claimed source bbc.com → ❌ Source Mismatch.
  • Hash lookup: result se content hash copy karke "Look up by record hash" mein daalein → record + "Integrity: Intact".
  • Ledger section mein naye blocks ki chain dikhayein.
  • Models section mein RoBERTa ko best model ke taur pe dikhayein.
Agar poocha jaye "100% accurate kyun nahi?"
"No fake news detector is 100% accurate, because the model learns linguistic patterns — it cannot verify facts. Our datasets are headline-level and LIAR is a known hard benchmark. That is why we built a dual trust model: AI classification plus blockchain-based source verification."

9Advanced: training, tests, admin

Ye sab project folder mein Command Prompt khol kar chalayein. Normal demo ke liye in ki zaroorat nahi.

Tests chalana (14 tests)

.venv\Scripts\python -m pytest -v

Verified source add / remove karna (Ganache chal raha ho)

.venv\Scripts\python -m blockchain.manage sources
.venv\Scripts\python -m blockchain.manage add-source geo.tv
.venv\Scripts\python -m blockchain.manage remove-source geo.tv

Models dobara train karna

.venv\Scripts\python -m ml.data
.venv\Scripts\python -m ml.train --models logistic_regression random_forest svm cnn lstm
set ROBERTA_EPOCHS=2
.venv\Scripts\python -m ml.train --models roberta
RoBERTa training CPU pe ~3 ghante leti hai aur purane model ko replace kar deti hai. Training ke dauran app ya heavy software na chalayein.

Blockchain reset karna (saare records mitaa kar naya contract)

Ganache window band karein, phir blockchain\chain-data folder aur blockchain\deployment.json file delete karein. Agli dafa start.bat chalane pe naya contract khud deploy ho jayega.

10Masle aur hal (Troubleshooting)

MaslaHal
